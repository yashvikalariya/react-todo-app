# React To-Do App

A simple and professional To-Do App built using React.

## 🚀 Features

- Add Task
- Edit Task
- Delete Task
- Complete / Uncomplete Task
- Filter Tasks
  - All
  - Active
  - Completed
- Task Statistics
- Clear Completed Tasks
- Empty Task Message
- Local Storage

## 🛠️ Technologies Used

- React
- JavaScript
- HTML
- CSS
- Local Storage
